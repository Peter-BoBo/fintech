CMD 콘다 명령어

콘다 활성화: conda activate 가상 환경명
콘다 비활성화: conda deactivate
가상환경 만들기: conda create -n 가상 환경명 python=버전
패키지 설치: conda install 패키지명
설치된 패키지 목록 보기: codna list
가상환경 목록 보기: conda info --envs
